How the values are made

Every implied value is one multiplication, and every ingredient comes from the snapshot itself — no name is priced by hand:

implied value = TVL × category multiple × growth × seasoning × breadth

  • Category multiple. The median market-cap/TVL of the live protocols in the same category, ratios trimmed to [0.005, 20]. A category needs at least 3 live peers to earn its own multiple; otherwise the global median is used. Live multiples run from about 0.04x for liquid staking to about 1.13x for canonical bridges, so one flat multiple would misprice nearly everything.
  • Growth. 1 + 0.45 · tanh(7-day TVL change / 30): a protocol growing into its launch is worth more than a shrinking one; unreported change counts as neutral.
  • Seasoning. 0.75 + 0.45 · min(age, 2 years) / 2 years: the longer a protocol has run with no token recorded, the more a launch has had time to become due. An unrecorded listing date counts as a flat 0.90.
  • Breadth. 1 + 0.04 per extra chain, up to five: a protocol already working on several chains launches to a wider base.

Each factor is rounded to 4 decimal places before it is applied, so the arithmetic on every detail page reproduces its board value exactly. The table below is recomputed by this page, in your browser, from the live protocols' own figures — it is not typed in.
